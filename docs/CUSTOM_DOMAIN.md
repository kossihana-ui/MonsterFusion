# 独自ドメインにする

2026-11-16。URLが覚えにくい、という話への手順です。

```
いま  https://kossihana-ui.github.io/MonsterFusion/
あと  https://monsterfusion.example/
```

**引っ越しはありません。** GitHub Pagesのまま、名前だけが変わります。

## コード側は準備済み

住所は**1か所にまとまっています**（`MONSTERFUSION_SITE`）。アセットの接頭辞も、
OGPの絶対URLも、共有文に載るURLも、全部そこから作られます。
**ドメインが決まれば、ワークフローの1行です。**

別のドメインでビルドして、4か所すべてが移ることは確認済みです。

## あなたがやること

### ① ドメインを買う

**私には買えません。** アカウント作成と支払いがあるので、ご自身でお願いします。

| | 目安 | 備考 |
|---|---|---|
| Cloudflare Registrar | `.com` 年1,500円ほど | 原価販売。更新しても値上がりしない。英語 |
| お名前.com | 初年度は安い／更新は高い | 日本語。**更新料を必ず確認してください** |
| Value Domain | 中くらい | 日本語 |

`.com` が無難です。`.jp` は年3,000〜4,000円ほど。`.app` はHTTPS必須ですが、
どのみちHTTPSなので問題ありません。

**名前の候補**（空きは registrar で確認してください。私には調べられません）：
`monsterfusion.com` / `monsterfusion.app` / `monster-fusion.com` など。

短くて、**口で言えて、打ち間違えないもの**を選んでください。ハイフンは口頭で
伝わりにくいので、できれば無しがいいです。

### ② DNSを設定する

買ったところのDNS設定画面で、次を登録します。

**ルート（`monsterfusion.example`）に A レコード4つ：**

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**`www` に CNAME 1つ：**

```
www  →  kossihana-ui.github.io
```

（`www` は無くても動きますが、付けておくと `www.` を付けて打った人も届きます。）

### ③ GitHubに登録する

リポジトリの **Settings → Pages → Custom domain** に買ったドメインを入れて Save。

DNSが行き渡るまで数分〜数時間かかります。緑のチェックが付いたら
**「Enforce HTTPS」にもチェック**を入れてください。証明書は自動です。

### ④ 教えてください

ドメイン名を教えてもらえれば、こちらで：

- ワークフローの `MONSTERFUSION_SITE` を差し替え
- `public/CNAME` を追加（デプロイのたびに設定が消えないように）
- 共有文・OGP・アセットの接頭辞が全部移ったことを確認
- 公開サイトで実際に開いて、画像も音も届くか確認

5分ほどで終わります。**鍵でも支払い情報でもないので、ドメイン名はそのまま
教えてもらって構いません。**

## 切り替えたあとのこと

- **古いURLもしばらく生きます。** GitHubが新しいドメインへ転送します
- すでに誰かが共有した `kossihana-ui.github.io/...` のリンクも飛びます
- ただし**セーブは移りません。** ブラウザの保存はドメインごとに別物なので、
  古いURLで遊んでいた人は、引き継ぎコードを使うか、最初からになります。
  **いま誰も遊んでいないうちに変えるのが、いちばん傷が浅いです**
