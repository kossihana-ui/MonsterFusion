# ふりーむ！に出す

2026-11-24。**費用は0円**です。ただし **itch.ioのパッケージはそのまま使えません。**
先に直すところがあります。

公式の案内を読んで書いています。

- 投稿について https://www.freem.ne.jp/information/for_game_creator
- 審査ガイドライン https://www.freem.ne.jp/information/policy_contents_guideline

---

## なぜ、ふりーむ！なのか

itch.ioの4日間の数字がこうでした。

```
Views +1 / Plays ±0 / 流入元 1つも増えず
来ているのは itch.io の新着一覧だけ
```

**新着一覧は出した直後しか効きません。**そこが切れたので、もう増えません。
ふりーむ！は**日本語のフリーゲームを探しに来る人が最初からいる場所**です。
itch.ioで足りなかったのは、ゲームではなく**母数**でした。

**HTML5のブラウザゲームを正式に受け付けています**（公式案内に明記）。
「ブラウザゲームピックアップ（DL無しで遊べるよ）」という枠もあります。

---

## 先に直すこと（4つ）

**これをやらずに出すと審査で止まります。**

### ① 共有ボタンを外す

審査ガイドラインの禁止事項です。

> 「WEBサイトへジャンプするもの」は掲載されません

いまの共有ボタンは **X（x.com）とLINE（social-plugins.line.me）を開きます。**
ふりーむ！版ではこの機能ごと出しません。

### ② 外部通信をゼロにする

> [Browser] 外部との通信（外部ライブラリ読み込み含む）。→ NG

**いまのビルドは、実は既に条件を満たしています。**配信ファイルを調べた結果です。

```
外部ホストの参照   x.com / social-plugins.line.me   ← ①で消える
                  kossihana-ui.github.io など       ← ①で消える
                  w3.org                            ← SVGの名前空間。通信しない
fetch の呼び出し   1か所（セーブ同期）
```

セーブ同期は **`VITE_SUPABASE_*` を渡したときだけ動きます。**
ふりーむ！版はこれを渡さずにビルドするので、**通信は一切発生しません。**

### ③ ReadMe を同梱する

> 説明書等(ReadMe.txt等）の著者情報を記したファイルが同梱されている。
> 「制作者名」「ゲーム名」が明記されている。

zipの中に `ReadMe.txt` を入れます。**ゲーム名とあなたの名義**が要ります。

### ④ 紹介文からURLを消す

> 他のプラットフォームへの言及・誘導や、ゲーム紹介文にURLや誘導の記載等はできません。

**itch.ioのことも、GitHub Pagesのことも書けません。** itch.io用に書いた
紹介文を流用するときは、そこだけ落とします。

## 手順

### Step 1　ふりーむ！IDを取る（無料）

https://www.freem.ne.jp/ の「ふりーむ！ＩＤ登録（無料）」から。

### Step 2　ブランド登録

ログインして「クリエイターズ・セントラル」へ。**サークル名／メーカー名**を
登録します。itch.ioの `Kureating544` と揃えておくと、同じ人の作品だと分かります。

### Step 3　ゲーム情報とファイル

| 項目 | 入れるもの |
|---|---|
| ゲーム名 | `MonsterFusion` |
| 種別 | **ブラウザゲーム（HTML5）** |
| カテゴリ | ロールプレイングゲーム |
| 制作ツール | JavaScript |
| 料金 | 無料 |
| ファイル | ふりーむ！用のzip（下記） |

**ゲーム名は3か所で一致している必要があります。** ガイドラインの指定です。

```
ゲーム画面に出る名前      MONSTERFUSION
Web上のゲーム名           MonsterFusion
ReadMe.txt のゲーム名     MonsterFusion
```

### Step 4　紹介文

itch.io版から**URLと他サイトへの言及だけ**落としたものです。

```
出会ったモンスターを融合して、自分だけの系譜を作るブラウザゲームです。
登録もダウンロードも要りません。開けば遊べます。

■ 見た目が、そのまま強さになります
体の部位は遺伝で決まります。尻尾からはバインド技、角からは突進技、
目からは魔法。どんな体に生まれたかが、何を覚えるかを決めます。

■ 負けると、仲間を失います
アリーナは勝ち抜き式です。評価は「何連勝できたか」だけ。
負けた仲間は二度と戻りません。だから連勝に意味があります。

■ はじめての人は、練習ラダーから
相手が弱く、負けても仲間を失いません。ボスの顔を見てから、本番へどうぞ。
```

### Step 5　「その他連絡事項」に書くこと

審査する人に先に伝えておくと早いものが2つあります。

**1. 絵の作り方**
```
キャラクターのドット絵と一部の背景は、生成AIを用いて制作したものを
加工して使用しています。第三者の著作物は使用していません。
```
**ガイドラインにAI生成物の規定は見当たりませんでした。** 書かずに出して
後から問題になるより、**先に申告して判断してもらうほうが安全です。**

**2. 画面の点滅**
```
攻撃がヒットした瞬間に1フレームの白い点滅があります。
連続する点滅ではなく、1回の攻撃につき1回です。
```
ガイドラインは「点滅は1/3秒に1回まで」です。該当しませんが、
**先に書いておけば審査で止まりません。**

### Step 6　審査

> 投稿されたゲームは簡単な審査を経て掲載されます。
> ゲーム内容の良し悪しの審査ではなく、プレイヤーが安心して遊ぶことが
> できる状態かを確認することが主な目的です。
