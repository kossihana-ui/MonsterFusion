# ウォーターヒール：魔力依存への変更依頼

ユーザーの要望：ウォーターヒールの回復量を、魔力に応じて多少増減させる。

UI修正済み：healイベントに回復専用の光・浮遊演出と実回復量の「＋N」を追加。amount=0は「HP満タン」。連続使用不可・MP不足では成功音や回復演出を出さず理由を表示。音源自体は変更していません。

## core側へ依頼する挙動

- ウォーターヒールは攻撃なし・連続使用不可を維持。
- 30を基準に、使用者の魔力で緩やかに増減。係数・上限下限は未確定です。
- 調整案（未承認の数値）：魔力70で30、魔力10につき1増減、24〜36に制限。極端な魔力でも回復だけで決着しなくなることを避ける意図です。
- HP上限で切り詰めた実回復量を既存の `BattleEffectEvent` の `heal.amount` に返す。UIはその数値をそのまま表示します。
- 低・中・高魔力、HP満タン、残り5だけ回復、連続使用不可、非攻撃をテストしてください。

## 説明表示に必要な公開API案

`getMoveHealing(skillId: string, caster: Monster, config?: BattleConfig): number`

戻り値：HP上限で切り詰める前の、その個体の回復量。図鑑・戦闘中の技説明に使用します。計算はcoreに集約し、index.tsから公開してください。既存APIに同等の機能を追加する形でも構いません。

現時点のUIの「HPを30回復」はcoreの `getMoveBehavior(skill.id).heal` を参照しています。API変更後に個体別の値へ接続します。
