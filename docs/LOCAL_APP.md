# このPCで開く

デスクトップの「MonsterFusion」をダブルクリックしてください。裏でこのPC専用のサーバーを起動して既定のブラウザで開きます。起動済みなら同じサーバーを使います。

- URL： http://127.0.0.1:5187/
- PCを再起動した後も、アイコンをダブルクリックすると起動します。
- 外部への公開はしません。開発用の5186とは別です。
- Node.jsとこのプロジェクトフォルダが必要です。フォルダを移動するとショートカットの再設定が必要です。
- 更新を反映するには `npm.cmd run build` 後に画面を再読み込みします。
- ゲーム進行の保存は未対応です。画面を閉じたり再読み込みしたりすると進行が失われます。
- 音・技編集のブラウザ保存は開発用URLと別になります。
- ログ： `%LOCALAPPDATA%\MonsterFusion`。

起動スクリプトは `scripts/open-local-app.ps1`、配信用サーバーは `scripts/local-app-server.mjs` です。Windows全体の実行ポリシーは変更しません。
