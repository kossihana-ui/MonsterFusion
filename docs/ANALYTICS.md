## 「何人が遊んだか」は、ここには出ません

Viewsは**ページを開いた回数**で、**遊んだ回数ではありません。** itch.ioの
ブラウザゲームでは、プレイ数は標準では取れません。どうしても知りたい場合は
Analytics画面の下にある **「Configure third-party analytics」** から
Google AnalyticsのIDを入れられます。**itch.io側に預けるだけで、こちらの
コードには何も書きません。**

ただ、**最初はやらなくていいと思います。** 遊ばれているかどうかは、
Views が伸びているかで十分に分かります。

### 見るべきは CTR です

**Viewsではありません。** Viewsは「どれだけ宣伝したか」で上下します。
**CTRは「一覧に並んだとき、他のゲームより押されたか」**で、カバー画像を
変えた効果はここに出ます。

```
いま     0.78%
相場     2〜5%（itchのブラウザゲーム）
```

**3〜5日は見てください。** 1日では表示回数が少なすぎて、上下が運に埋もれます。

実際に遊んだ人はこの数字より多いはずです。**比較には影響しません**（どちらの
日も同じ条件なので）。
