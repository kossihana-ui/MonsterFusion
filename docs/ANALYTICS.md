## 「何人が遊んだか」は、ここには出ません

Viewsは**ページを開いた回数**で、**遊んだ回数ではありません。** itch.ioの
ブラウザゲームでは、プレイ数は標準では取れません。どうしても知りたい場合は
Analytics画面の下にある **「Configure third-party analytics」** から
Google AnalyticsのIDを入れられます。**itch.io側に預けるだけで、こちらの
コードには何も書きません。**

ただ、**最初はやらなくていいと思います。** 遊ばれているかどうかは、
Views が伸びているかで十分に分かります。

## 比較のための基準値（2026-11-20）

カバー画像を差し替えた日の数字です。**次に見るとき、ここと比べます。**

```
公開から2日
Views            16
Browser Plays     3
Ratings           0
Collections       0
Comments          0
7日間の表示      385

```

流入元（30日）

```
t.co（Twitter）                3
itch.io 新着・無料・Web        2
itch.io 新着/人気・RPG         3
better-itch-search             1
自分のページ内                  2
```

### 見るべきは CTR です

**Viewsではありません。** Viewsは「どれだけ宣伝したか」で上下します。
**CTRは「一覧に並んだとき、他のゲームより押されたか」**で、カバー画像を
変えた効果はここに出ます。

```
いま     0.78%
相場     2〜5%（itchのブラウザゲーム）
```

**3〜5日は見てください。** 1日では表示回数が少なすぎて、上下が運に埋もれます。

### 注意

**Pages版に行った人はここに出ません。** スマホはPages版へ案内しているので、
実際に遊んだ人はこの数字より多いはずです。**比較には影響しません**（どちらの
日も同じ条件なので）。

## 2026-11-24：カバーを変えても、動きませんでした

```
              11-20      11-24
Views            16         17   （+1）
Browser Plays     3          3   （±0）
7日間の表示     385        414
CTR           0.78%      0.72%
流入元        8種類      8種類（1つも増えていない）
```

**カバー画像の効果は、数字に出ていません。**

CTRは下がっていますが、**これは「悪化した」ではありません。** 414回の表示で
0.72%は**クリック3回**です。前回も3回でした。**この回数では、1クリック動くだけで
0.2%動きます。** 差を測れる量ではありません。

**つまり、こう言うべきでした。** 385回の表示で3クリックという数字を見て、
「画像が弱い」と判断しましたが、**385回は画像の良し悪しを測れる回数ではありません。**
カバーを作ったこと自体は無駄ではありませんが、**これが原因だという私の読みは
根拠が薄かったです。**

### 本当の問題は、表示元が1つしかないことです

流入元は4日間で**1つも増えていません。**

```
t.co（Twitter）   3    ← おそらくあなたの投稿
itch.io の新着一覧  7    ← itchが勝手に出しているだけ
その他             2
```

**itch.ioの「新着」以外から、誰も来ていません。** そして新着一覧は、
**出した直後の数日しか効きません。** 週400回の表示は、その残りです。
ここから自然に増えることはありません。

**ページを直しても、ここは動きません。** 見られる場所に置くかどうかの問題です。
