# 体の特徴から覚える技と、技セット

[MOVE_LOADOUT_HANDOFF.md](../../MonsterFusion-UI/src/mocks/MOVE_LOADOUT_HANDOFF.md) への対応です。依頼どおりのAPIを実装しました。

## 1. API

```ts
import {
  getLearnableMoves, validateMoveLoadout, createDuelWithLoadouts,
  defaultLoadout, reconcileLoadout, MAX_MOVE_SLOTS, MOVE_TIERS,
} from '@core/core/index.ts';
```

### 覚えられる技

```ts
getLearnableMoves(monster);
```

```ts
{
  skill: { id: 'final-tail', name: 'ファイナルテール', power: 230,
           scaling: 'attack', element: 'fire', cost: 16 },
  reason: 'トゲの尻尾で覚える',
  category: 'finisher',
  source: 'tail',          // 習得元の部位。図鑑で部位とひも付けたいとき用
}
```

`skill.scaling` が `attack` なら⚔物理、`magic` なら✦魔法です。`skill.element` は属性色に使えます。

### 技セットの検証

```ts
validateMoveLoadout(monster, ['fang-bite', 'final-tail']);
// { ok: true, loadout: { monsterId, skillIds } }
// { ok: false, message: 'Ignisはその技を覚えていません。' }
```

メッセージは日本語です。そのまま表示できます。

### バトルへの反映

```ts
createDuelWithLoadouts(a, b, loadouts, config?);
createBattleWithLoadouts(teams, loadouts, config?);   // N対N用
```

技セットが無い個体は既定セットで戦います。**不正な技は無視されます**（セットごと拒否はしません）。

## 2. 習得の判定

**発現している特徴（phenotype）だけを見ます。** 隠れ遺伝子では解禁されません。「トゲの尻尾の遺伝子を持っている」ことと「トゲの尻尾が生えている」ことは別で、後者だけが技になります。

融合後は子の特徴で自動的に再評価されます。親が覚えていた技を子が覚えているとは限りません。

技は30種類を定義しています。例:

| 部位 | 値 | 技 | 種別 |
|---|---|---|---|
| 尻尾 | spiked | ファイナルテール | 大技 |
| 尻尾 | vine | バインドウィップ | 通常 |
| 角 | spiral | ラムチャージ | 大技 |
| 角 | crown | クラウンブレイク | 大技 |
| 翼 | ethereal | ソウルウィング | 大技 |
| 口 | maw | デスバイト | 大技 |
| 頭飾り | crown | ロイヤルオーダー | 大技 |
| 大きさ | giant | ジャイアントプレス | 大技 |

全件は `MOVE_CATALOGUE` / `allMoveDefinitions()` で取得できます。**部位と値の組み合わせを1行足すだけで技が増えます。**

属性は、その技固有のものを持つ場合（バインドウィップは土）と、モンスター自身の属性を継ぐ場合（ファイナルテールは炎のモンスターなら炎）があります。後者により、同じ技でも属性色が個体ごとに変わります。

## 3. 枠と威力

```ts
MAX_MOVE_SLOTS   // 3
MOVE_TIERS       // { basic: {power:100, cost:0}, feature: {power:150, cost:7},
                 //   finisher: {power:230, cost:16}, support: {power:0, cost:2} }
```

通常攻撃と守るは枠を消費しません。**大技も通常技と同じ枠に入ります。**

`MOVE_TIERS.basic` はどの技の段でもありません。**通常攻撃の威力**であり、他の威力を読むための基準です。MP0・枠0です。

大技はMP消費だけで扱っています。命中率・溜め・クールダウンは入れていません。

### 共通技はありません（2026-10-27変更）

**`strike` と `sig-*` は削除しました。** 全個体が同じ技を持っていると、3枠のうち2枠が全員同じになり、「どんな体に生まれたか」を見る理由が消えるためです。

- `getLearnableMoves()` は部位由来の技だけを返します
- `LearnableMove.source` は**必ず部位**です（`null` は型には残していますが返りません）
- **0枠を許可します。** 通常攻撃と守るが枠外にあるので、空でも戦えます

### 枠が0になる個体はいるか

**測定した範囲ではいません。** ルートモンスター400体、融合12世代×60系統（720体）で、最低2技でした。アリーナの敵300体も2〜8技です。0枠は**プレイヤーが自分で空にしたときだけ**起こります。

## 4. 既定の技セット

```ts
defaultLoadout(monster);
```

威力の高い特徴技から埋めますが、**大技は1つだけ**です。

大技はMP16、開始MPは10なので、大技2つの既定セットは「最初の2ターン何もできないセット」になります。4枠＋共通技の時代はMP2の `strike` が受け止めていました。3枠でそれが無くなったので、既定セットが自分で保証します。プレイヤーが2つ目の大技を選ぶのは自由です。

```
Moss    bind-whip pollen-burst              （2技しか覚えないため2枠）
Ignis   final-tail fang-bite power-slam      （以前は大技2つが入っていた）
Aqua    death-bite tail-sweep magic-eye
```

技セットが未設定の個体は、これで戦います。

## 5. 保存

**遺伝情報とは分けて保存します。** 技セットは「プレイヤーが決めたこと」であり、モンスターの性質ではないためです。

```ts
serializeSaveFile(monsters, { loadouts });
deserializeSaveFile(json).value.loadouts;
```

`MonsterSaveFile.loadouts` に入ります。モンスター本体のデータには一切混入しません。

**読み込み時は修復します。拒否しません。**

- 覚えられなくなった技 → その技だけ落とす
- 4つ入っていた旧セーブ → 先頭3つを残す
- 存在しないモンスターを指す技セット → 落とす
- 全部落ちた場合 → 既定セットに戻す
- **最初から空だった場合 → 空のまま**

最後の2つは別の話です。`['strike', 'sig-earth']` のような旧セーブは「技を指定していたが、その技が無くなった」ので既定セットに戻します。一方、`[]` は「プレイヤーが枠を空にした」という選択なので尊重します。`skillsForLoadout` も同じで、技セットを渡さなければ既定、空の技セットを渡せば空です。

融合で体が変わった個体の技セットが原因で、コレクション全体が読めなくなる事態を避けるためです。技セットが無い旧セーブもそのまま読めます。

## 6. 注意点

**`startingMp` を 20 → 10 に下げました。** 大技（MP16）が初手から撃てると、ただの強い通常攻撃になってしまうためです。現在は2〜3ターン目から撃てます。MPバーの表示に影響します。

**技セットの枠は埋めません。** 2つ選んだら2つのままです。実装の途中で既定技を補充する作りにしていましたが、プレイヤーが選んでいない技が勝手に入るのは誤りなので外しました。

**通常攻撃が、攻撃力と魔力の高い方で殴るようになりました。** 以前は `strike` がこの役をしていました（攻撃力と魔力を比べて高い方で計算する）。共通技を削除したので、魔力型なのに特徴技が全部物理の個体が、自分の魔力をどこにも使えなくなります。通常攻撃はMPが尽きたときの全員の逃げ道なので、ここに移しました。測定: 魔力＞攻撃力の個体は400体中186体、うち既定セットに魔法技が1つも入らないのは51体です。

**バランスへの影響は [FEATURE_ONLY_MOVES.md](FEATURE_ONLY_MOVES.md) にまとめました。** 数値も含めてそちらを見てください。スターターの勝率差が広がっています。
