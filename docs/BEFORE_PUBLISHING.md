# 公開前に必要なこと（2026-11-14 調査）

「宣伝なしでどれぐらい広まるか試したい」に向けて、**実際に調べた結果**です。推測ではなく、ビルドと実機で確認した事実だけ書いています。

## 1. いちばん大きな問題：セーブがありません

**リロードするとすべて消えます。** モンスターも、パーツも、アリーナの進行も。残るのは連勝記録とプレイヤー名だけです。

宣伝なしで広がるかを試す場合、これは致命的です。知らない人が20分遊んで、タブを閉じるかうっかり更新した瞬間にゼロに戻ります。**戻ってくる理由がなくなり、人に勧める理由もなくなります。**

coreの保存APIは完成しています（`serializeSaveFile` / `deserializeSaveFile` / `restoreSession`、マイグレーション対応済み）。**localStorageに繋ぐだけ**で、新しい仕組みは要りません。ここが公開前の最優先です。

## 2. SNSで広がるために効くもの

### OGP画像とdescriptionがありません

`index.html` にあるのは `<title>` と viewport だけです。**今リンクを貼ると、タイトルだけの味気ないカードになります。**

宣伝せずに広がるかを試すなら、ここが単体でいちばん効きます。

- `og:title` / `og:description` / `og:image`（1200×630）
- `twitter:card` は `summary_large_image`
- モンスターの絵が出るカードにする

### 連勝の共有ボタンがありません

せっかく「今週の挑戦」が全員同じ並びになったので、**「今週の挑戦で12連勝」を共有できる**と、宣伝なしで広がる導線になります。共有文に週（2026-W46）を入れると、見た人が同じ条件で挑めます。

記録には既にプレイヤー名・モンスター名・見た目・ラダーが入っているので、**共有用の文面はすぐ作れます。**

## 3. ホスティング

ビルドは静的ファイルだけ（`dist/`）なので、どこにでも置けます。

| | 注意点 |
|---|---|
| Cloudflare Pages / Netlify / Vercel | ルート配信なので**そのまま動きます**。無料枠で足ります |
| GitHub Pages（プロジェクトサイト） | `/MonsterFusion/` 配下になるため、`vite.config.ts` に `base` の設定が必要です。**現在 `base` は未設定**（＝ルート前提）。またリポジトリが非公開のままでは無料枠で公開できません |

音声が48ファイル、ボス画像が2.3MBあります。全体で数MB程度なので問題はありませんが、**ボスの概念画は実寸に縮小したほうが初回表示が速くなります**（現在2329600バイト）。

## 4. スマホで見たときの状態（375×812で確認）

| | 結果 |
|---|---|
| 横スクロール | **なし**（0px）。崩れていません |
| 連打（ファイナルテール） | **タップで動きます**。キーボード不要 |
| サイドバー | 上部に横並びになりますが、**文字が縦に潰れて読みにくい**です |
| ボタンの最小高さ | **29px**。指で押すには小さめ（推奨44px） |

遊べますが、**スマホで最初に見たときの印象は弱い**です。SNSからの流入はほぼスマホなので、サイドバーとボタンの高さは直す価値があります。

## 5. 初見の人がぶつかる壁

測定済みの数字です。

```
スターターのままアリーナに挑んだときの到達
Moss   中央値 3戦    Ignis 中央値 2戦    Aqua 中央値 3戦
```

**初見の人は2〜3戦で負けます。** 負けると出場した仲間を失い、3体しかいないので、**10分ほどでゲームオーバーに到達します。**

これは「難しい」ではなく「何も分からないうちに終わる」状態です。宣伝なしで広がるかを試すなら、最初の5分で「このゲーム面白いかも」と思ってもらう必要があります。

考えられる対策（どれも小さい）：

- 最初の数戦だけ明確に弱い「練習ラダー」を用意する
- 負けても1体目だけは失わない（チュートリアル保護）
- 入口で「負けると失います」をもっと強く出す（今は文章の中に埋もれています）

**私のおすすめは練習ラダーです。** 自由に挑戦モードの難易度を下げたものを「はじめての挑戦」として置けば、既存の仕組みのままできます。

### 2026-11-14 追記：実装しました

「はじめての挑戦（練習）」を入れました。相手は0.75倍、負けても仲間を失わず、そのかわり**素材もドクロゲソも出ず、順位にも加わりません**。到達の中央値は3/2/4戦から**10/5/12戦**になり、**6戦目のボスまで届きます**。記録のない人には初期選択として出ます。詳細は [PRACTICE_LADDER.md](../../MonsterFusion-Core/docs/PRACTICE_LADDER.md)。

## 7. 公開しても困らないこと（確認済み）

- 音源・画像はすべてオリジナル（手続き生成、またはユーザー提供画像）

- 外部通信なし。オフラインでも動きます
