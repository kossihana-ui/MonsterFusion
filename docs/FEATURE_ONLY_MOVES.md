## 2. 空の技セットの扱い

ここだけ依頼文より細かく分けました。**「空」には2種類あるためです。**

```ts
skillsForLoadout(monster)                                  // 既定セット（誰も選んでいない）
skillsForLoadout(monster, { monsterId, skillIds: [] })     // 空（プレイヤーが空にした）
reconcileLoadout(monster, [])                              // 空のまま
reconcileLoadout(monster, ['strike', 'sig-earth'])         // 既定セット（技を指定していたが消滅した）
```

`[]` は「枠を空にする」という選択なので尊重します。`['strike', 'sig-earth']` のような旧セーブは「技を選んでいたが、その技が無くなった」ので既定セットに戻します。素手で戦う選択ではありません。

**技セットを渡さない**のと**空の技セットを渡す**のは別だということです。以前は `requested?.length` で両方を同じに扱っていました。

## 3. セーブの互換性

**マイグレーション不要です。`schemaVersion` は4のままです。**

読み込み時に全技セットが `reconcileLoadout` を通るので、旧セーブは自動で修復されます。

| 旧セーブの中身 | 読み込み後 |
|---|---|
| `['sig-fire', 'strike', 'final-tail', 'ram-charge']` | `['final-tail', 'ram-charge']` → 落ちた分は補充せず、残った2つ |
| `['strike', 'sig-earth']` | 既定セット（全部消えたため） |
| 4技すべて部位技 | 先頭3つ |

## 4. 修正した不具合2件

依頼の実装中に見つけたものです。どちらも3枠にしたことで表に出ました。

### 既定セットが大技2つになっていた

`defaultLoadout` は威力順に埋めていました。Ignisは大技を2つ覚えるので、**MP16の技2つ＋MP7の技1つ**という既定セットになり、開始MP10では最初の2ターン撃てる技が1つしかありません。4枠＋`strike`（MP2）の時代はそれで成立していました。

**大技は既定セットに1つだけ**にしました。2つ目を選ぶのはプレイヤーの自由です。

```
Ignis   前: final-tail(16) ram-charge(16) fang-bite(7)
        後: final-tail(16) fang-bite(7) power-slam(7)
```

これでアリーナのボス戦が通るようになりました（修正前は5戦目で負けていました）。

### 期待ダメージが「攻撃しない技」を攻撃として評価していた

`expectedDamage()` が `skill.power` しか見ていませんでした。**テールスイープは攻撃しない技ですが、特徴技の威力150を持っています**（`attacks: false`）。そのため敵AIがこれを「盤面で最強の一撃」と判断し、毎ターン撃って0ダメージを出し続けていました。

修正後は技の挙動を見ます。

- 攻撃しない技は **0**
- 仕様で上書きされた威力を使う（ツインラッシュは150ではなく70）
- 多段攻撃は回数を掛ける
- 成功率60%の技は0.6を掛ける
- 砕牙は防御力を無視した値で見る

**これはUIが技の横に出す数値でもあります。** 回復技にダメージ予測が出ていたら、それが原因です。

## 5. 通常攻撃が高い方の攻撃力で殴るようになりました

**依頼にない変更です。** 共通技を消すと必要になったため入れました。不要であれば戻します。

`strike` は「攻撃力と魔力を比べて高い方で計算する」技でした。これを消すと、**魔力型なのに特徴技が全部物理**の個体が、自分の魔力をどこにも使えなくなります。

通常攻撃はMPが尽きたときの全員の逃げ道なので、この役を通常攻撃に移しました。「モンスターが自分の持っているもので殴る」という意味です。

測定: 魔力＞攻撃力の個体は400体中186体、うち既定セットに魔法技が1つも入らないのは51体（27%）です。

## 6. バランス（決着）

### 入れたもの

ご指示で2つ入れました（どちらも2026-10-28）。

1. **効果中のデバフは再付与できません。** 残りターンは増えず、リセットもされません。バフは今までどおり上書きできます。仕様は [MOVE_EFFECTS.md](MOVE_EFFECTS.md) の7章、UIに追加される `noEffect` イベントは8章です
2. **暗闇の回避率を 0.75 → 0.5 にしました。** `DEFAULT_BATTLE_CONFIG.blindEvasion` の1行です

順に測ったので、以下はその順で並べています。1だけでは足りず、2で収まりました。

### 再測定（400戦×総当たり）

```
                       部位技のみ      ＋再付与禁止
Moss                     57.1%           44.4%
Ignis                    11.8%           20.6%
Aqua                     79.6%           84.0%
差                     67.9ポイント    63.4ポイント
```

**これだけでは効きませんでした。** 67.9 → 63.4 で、元の37.5には届きません。はっきり書きます。**1だけで足りると書いたのは私の誤りでした。**

### 効かなかった理由

同じ100戦を、暗闇が実際にかかっている時間で測りました。

```
                        部位技のみ      ＋再付与禁止
マジックアイの使用回数     366回           370回
暗闇が入った回数           366回           200回
「すでに暗闇」で不発         0回           170回
Ignisが暗闇中に行動した   604/612回       589/611回
                           (99%)           (96%)
```

**無駄な撃ち直しが170回なくなっただけで、暗闇が切れている時間は3%しか増えていません。**

暗闇は2ターンですが、かけたターンは経過扱いにならないので**実際には3ターン覆います**。一方マジックアイはMP7、MP回復は毎ターン3なので、**1.6ターンに1回撃てます**。1.6 < 3 なので、切れる前に必ず次が入ります。再付与を禁止しても、切れた瞬間に入れ直せるのなら隙間はできません。

**期間を変えても同じです。** 暗闇を1ターンにして測りましたが、**差は63.4で1ポイントも動きません**（1ターン＋かけたターンで2ターン覆い、2 > 1.6のため）。

つまり**暗闇の期間はこのゲームの勝敗に効いていません。** 効いているのは「暗闇の1ターンがいくら高いか」だけです。

### 動く数値は1つでした → 0.5にしました

`DEFAULT_BATTLE_CONFIG.blindEvasion` だけを変えて測った結果です。

```
blindEvasion       Moss     Ignis    Aqua      差
0.75（当初）       44.4%    20.6%    84.0%    63.4
0.60               45.3%    25.5%    77.8%    52.3
0.50 ← 採用        45.8%    30.8%    72.8%    42.0
0.40               46.1%    37.0%    66.0%    29.0
```

**ユーザー判断で 0.5 にしました（2026-10-28）。** 変更は `blindEvasion` の1行だけで、コードには触っていません。

```
                  部位技のみ   ＋再付与禁止   ＋暗闇0.5   （共通技があった頃）
Moss                57.1%        44.4%        45.8%
Ignis               11.8%        20.6%        30.8%
Aqua                79.6%        84.0%        72.8%
差                  67.9         63.4         42.0            37.5
```

最も偏っていたAqua対Ignisが **96% → 77%** になりました。Ignisの全体勝率は 11.8% → 30.8% です。

暗闇中の時間そのものは変わりません（Ignisの行動のうち95%が暗闇中）。変わったのは、その1ターンで外す確率です。

```
                        部位技のみ   ＋再付与禁止   ＋暗闇0.5
Ignisが暗闇中に行動         99%         96%          95%
暗闇で外した割合            43%         48%          34%
```

**UI側に1点あります。** 「暗闇は物理を75%回避」と書いている箇所があれば50%に直す必要があります。

**同じことが起きたら落ちるテストを足しました。** スターター総当たり100戦で、どの1体も勝率15〜90%、差55ポイント未満であることを確認します。0.75に戻すと落ちます（「the starters are 61.5 points apart」）。今回は1つの技が勝率表を決めているのにテストが1件も落ちなかったので、その穴を埋めてあります。

### 再付与禁止で下がったもの

**Mossが 57.1% → 45.8% に下がりました。** バインドウィップでバインドを撃ち直して相手の行動を奪う戦い方が成立しなくなったためです。これは制限の意図どおりの結果です（バインドは1〜2ターンの技なので、1〜2ターンしか効かなくなりました）。

結果としてMossは3体のほぼ中央（45.8%）に来ています。偏っていたのを戻した、という見方もできます。

戻すべきであれば、`canApplyStatus` が `false` を返す条件から `bind` を外すだけです。ただし「暗闇だけ特別扱い」になります。

## 7. 枠が0になる個体

**測定した範囲ではいません。**

| 母集団 | 覚える技の数 | 0技 |
|---|---|---|
| ルートモンスター400体 | 2〜8 | 0体 |
| 融合12世代×60系統（720体） | 2〜8 | 0体 |
| アリーナの敵300体 | 2〜8 | 0体 |

ただし**ルールとしては0技を許しています**。武器になる特徴を1つも持たない体なら0技が正しい答えで、その個体も通常攻撃と守るで戦えます。将来アレルプールが変わって0技が出ても壊れません。テストで測定値を固定してあるので、変わればテストが落ちます。

なお **Mossは2技しか覚えません**（バインドウィップ・ポレンバースト）。3枠目は永久に空です。IgnisとAquaは3枠埋まります。意図どおりであればそのままで構いませんが、Mossに技を1つ足すなら部位を1つ追加するか、`MOVE_CATALOGUE` に1行足すだけです。
