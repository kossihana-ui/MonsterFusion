# スクロールしない

2026-11-16。決まりごとです。

> **どの画面でも、基本的にスクロールはNG。**

ゲームだからです。押すものと、押した結果が、同時に見えていない画面は操作できません。
戦闘画面で起きていたことが、ほかの画面でも全部起きていました。

## 測った値（この決まりを立てた時点）

画面の下端から、はみ出していたピクセル数です。

| 画面 | 1280×800 | 375×812 |
|---|---|---|
| モンスター図鑑 | 225 | 864 |
| 融合のアトリエ | **775** | **1123** |
| ソウルメイク | 306 | 1110 |
| アリーナ入口 | 15 | 555 |
| モンスター登録 | 0 | 0 |
| セーブの引き継ぎ | 120 | 416 |

**全部、ページごと動いていました。** ナビゲーションも、タイトルも、一緒に消える。
ボタンを探すと、そのボタンが何に効くのかが見えなくなる。

## 第一段階：窓は動かない（完了）

`src/styles/app-frame.css`。シェルを**画面ちょうど1枚の枠**にしました。

- `body` は `overflow: hidden`。**ページそのものは、もう絶対に動きません**
- サイドバーと上部バーは固定。常に見えています
- 動けるのは中身の領域だけ

測り直すと、**全画面で窓のスクロール量が0**になりました。

```
          窓     中身
図鑑       0     208
融合       0     737
ソウルメイク  0     284
アリーナ入口  0      14
登録        0       0
引き継ぎ     0     110
```

**これは床であって、目標ではありません。** 中身がまだはみ出しています。

## 第二段階：中身を収める（これから）

画面ごとの作業です。やり方は3つしかありません。

1. **減らす** — 戦闘中のタイトルや説明文のように、その瞬間に要らないものを出さない
2. **畳む** — 説明を ⓘ の中へ。常時表示をやめる
3. **区切る** — 一覧だけは別。50体の図鑑は、どう詰めても1画面に入りません

3番は正直に決める必要があります。**図鑑のように際限なく増える一覧は、
「ページの中の、枠で囲まれた一覧だけが動く」** 形にします。ページは動かず、
周りのボタンも見出しも据わったまま、一覧の中だけがめくれる。これはスクロールと
いうより**ページめくり**に近い扱いです。

## 設計の基準になる画面サイズ

**ここが決まっていません。**

「どの画面でもスクロールしない」は、**どの画面を基準にするか**で作業が変わります。

| 届け方 | 基準サイズ | 収めやすさ |
|---|---|---|
| いまのWeb（どんな端末でも） | 不定 | いちばん難しい。縦812pxの電話も、縦600pxのノートもある |
| itch.io に埋め込む | **こちらで指定できる**（例 1280×800） | 一気に楽になる。その枠に収めればよい |
| ダウンロード版 | ウィンドウサイズを固定できる | 同上 |

**届け方を決めると、この作業の難しさが半分になります。**
