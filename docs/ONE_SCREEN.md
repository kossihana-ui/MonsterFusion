# スクロールしない

2026-11-16。決まりごとです。

> **どの画面でも、基本的にスクロールはNG。**

ゲームだからです。押すものと、押した結果が、同時に見えていない画面は操作できません。
戦闘画面で起きていたことが、ほかの画面でも全部起きていました。

## 測った値（この決まりを立てた時点）

画面の下端から、はみ出していたピクセル数です。

| 画面 | 1280×800 | 375×812 |
|---|---|---|
| モンスター図鑑 | 225 | 864 |
| 融合のアトリエ | **775** | **1123** |
| ソウルメイク | 306 | 1110 |
| アリーナ入口 | 15 | 555 |
| モンスター登録 | 0 | 0 |
| セーブの引き継ぎ | 120 | 416 |

**全部、ページごと動いていました。** ナビゲーションも、タイトルも、一緒に消える。
ボタンを探すと、そのボタンが何に効くのかが見えなくなる。

## 第一段階：窓は動かない（完了）

`src/styles/app-frame.css`。シェルを**画面ちょうど1枚の枠**にしました。

- `body` は `overflow: hidden`。**ページそのものは、もう絶対に動きません**
- サイドバーと上部バーは固定。常に見えています
- 動けるのは中身の領域だけ

測り直すと、**全画面で窓のスクロール量が0**になりました。

```
          窓     中身
図鑑       0     208
融合       0     737
ソウルメイク  0     284
アリーナ入口  0      14
登録        0       0
引き継ぎ     0     110
```

**これは床であって、目標ではありません。** 中身がまだはみ出しています。

## 第二段階：中身を収める（これから）

画面ごとの作業です。やり方は3つしかありません。

1. **減らす** — 戦闘中のタイトルや説明文のように、その瞬間に要らないものを出さない
2. **畳む** — 説明を ⓘ の中へ。常時表示をやめる
3. **区切る** — 一覧だけは別。50体の図鑑は、どう詰めても1画面に入りません

3番は正直に決める必要があります。**図鑑のように際限なく増える一覧は、
「ページの中の、枠で囲まれた一覧だけが動く」** 形にします。ページは動かず、
周りのボタンも見出しも据わったまま、一覧の中だけがめくれる。これはスクロールと
いうより**ページめくり**に近い扱いです。

## 設計の基準になる画面サイズ

**ここが決まっていません。**

「どの画面でもスクロールしない」は、**どの画面を基準にするか**で作業が変わります。

| 届け方 | 基準サイズ | 収めやすさ |
|---|---|---|
| いまのWeb（どんな端末でも） | 不定 | いちばん難しい。縦812pxの電話も、縦600pxのノートもある |
| itch.io に埋め込む | **こちらで指定できる**（例 1280×800） | 一気に楽になる。その枠に収めればよい |
| ダウンロード版 | ウィンドウサイズを固定できる | 同上 |

**届け方を決めると、この作業の難しさが半分になります。**

## 2026-11-16 追記：1280×800 に決めて、収めました

基準は **1280×800**。その枠で、内容がはみ出したピクセル数です。

```
              直す前    直したあと
図鑑            135        0
融合            759        0
ソウルメイク      210        0
アリーナ入口       15        0
モンスター登録      0        0
セーブの引き継ぎ    38        0
戦闘中（開始時）   132        0
戦闘中（1ターン後） 212        0
```

**窓も、中身も、どこもスクロールしません。**

### やったこと

**減らした** — 各画面の100pxのタイトル説明文。ナビとパンくずが同じことを
言っています。戦闘中の「MPは毎ターン+4」。空の結果パネルの「まだ何も
起きていません」。装飾のフッター。

**横に並べた** — 1280pxは横に広く、内容は縦に長い。これが問題の本体でした。
**融合**は親2体を左、押すもの全部を右へ（759→0）。**戦闘**も戦場を左、
コマンドを右へ。縮めるより、並べるほうが効きます。

**枠で区切った** — 際限なく増える2つ。**図鑑の一覧**と**戦闘ログ**です。
50体の図鑑はどう詰めても1画面に入りません。この2つだけ、自分の場所で
中身が動きます。**周りの見出しもボタンも、一切動きません。**

### 注意（引っかかったところ）

`main` を縦方向のflexにしました（一覧に余った高さを渡すため）。
**flexの子は `float` が効きません。** 戦闘画面の左右2列をfloatで組んでいたので、
これが黙って1列に戻っていました。gridに置き換えて直しています。
以後、この中でfloatは使えません。

### まだ残っていること

**スマホは別作業です。** いまの基準は1280×800で、375×812では依然として
はみ出します。itch.ioに1280×800で埋め込むなら、この作業で足ります。
