# 依頼：倍率の演出（通常モーションのあとに「×2倍」＋オーケストラ・ヒット）

core側（`claude-core`）の対応は**完了しています**。UI側の実装だけお願いします。

## 1. やりたいこと

攻撃力2倍や種の追撃など、**倍率が乗ったとき**に気持ちよさを出したいです。

```
通常の攻撃モーション → ヒット → （ここで一拍おいて）→ 「×2倍」＋オーケストラ・ヒット → ダメージ数値
```

倍率が乗っていない通常のヒットでは**何も出しません**。

## 2. データ（core側で用意済み）

`BattleLogEntry.effects` の `damage` イベントに、**なぜ大きくなったか**が入っています。

```ts
{
  type: 'damage',
  amount: 15,
  critical: false,
  hit: 1, hits: 1,
  boostTotal: 3,                 // 合計倍率。boosts の積
  boosts: [
    { source: 'attackUp', reason: '攻撃力上昇', factor: 2 },
    { source: 'seed',     reason: '種',       factor: 1.5 },
  ],
}
```

- **`reason` は日本語でそのまま表示できます。** 変換表を作らないでください
- `source` は演出の出し分け用の識別子です（文字列リテラルのユニオン）
- **通常のヒットには `boosts` も `boostTotal` も付きません**（`undefined`）
- 型は `import type { DamageBoost } from '../core/index.ts'` で取れます

`source` の全種類:

| `source` | `reason` | 出る場面 |
|---|---|---|
| `attackUp` | 攻撃力上昇 | ラムチャージ等で攻撃力2倍の状態 |
| `seed` | 種 | 種を付けた本人が炎で追撃（×1.5） |
| `targetDefending` | 守りを突いた | ファングバイト／ピアースビーク |
| `targetNotDefending` | 守っていない | ピアースビーク（×0.5。**下がる方向**） |
| `targetBound` | 拘束中 | コイルクラッシュ（×2） |
| `selfPoisoned` | 毒をおして | パワースラム（自分が毒なら×2） |
| `element` | 属性 | 属性相性（1.0のときは入りません） |

## 3. 発動条件

```ts
const boosted = (d.boosts ?? []).filter((b) => b.source !== 'element');
const factor = boosted.reduce((p, b) => p * b.factor, 1);
if (factor > 1) { /* 演出を出す */ }
```

**`element` を除いて判定することを推奨します。** 属性相性は既に専用の表示があるので、そこにオーケストラ・ヒットまで重ねると毎ターン鳴ってしまい、特別感がなくなります。属性も含めたいなら `boostTotal > 1` だけで済みます（判断はお任せします）。

`factor < 1`（ピアースビークの×0.5など）は**演出なし**でお願いします。弱くなったことを派手に出す必要はありません。数値の色を変える程度で十分です。

## 4. 表示内容

- 1つだけのとき: **`×2倍`** を大きく、下に小さく `攻撃力上昇`
- 複数のとき: **`×3倍`** を大きく、下に `攻撃力上昇 ×2 / 種 ×1.5`

```
        ×3倍
  攻撃力上昇×2 ・ 種×1.5
```

`boostTotal` は小数第2位まで丸めてあります。`×1.5倍` のように**小数はそのまま**出してください（`×1倍` は出ません）。

## 5. タイミング（重要）

**通常のモーションを省略しないでください。** 先に普通に当てて、その後に倍率を出すのが気持ちよさの理由です。

```
0ms      攻撃モーション開始（既存のまま）
         ヒット（既存のヒットエフェクト・画面揺れ）
+120ms   一拍おく（ここが効きます。短すぎると普通のクリティカルに見えます）
+120ms   「×2倍」を中央に出す ＋ オーケストラ・ヒット
         文字は 1.4倍 → 1.0倍 に 180ms でスケールイン、軽く画面を白くフラッシュ
+500ms   文字を保持
+700ms   フェードアウトしながら、ダメージ数値をHPバーに反映
```

数値は目安です。**「一拍おく」ところだけ守っていただければ**、あとは触りながら調整してください。

## 6. 多段攻撃

`hits > 1` の技（ツインラッシュ、ダブルゴア）は、**1発ごとに `damage` イベントが来ます**。倍率は各発に同じものが入っています。

**演出は最後の1発のあとに1回だけ**出してください。倍率は `hit === hits` のイベントから取ります。合計ダメージの方が気持ちいいので、必要なら各発の `amount` を足して出してください。

## 7. クリティカルとの重複

`critical: true` と倍率は同時に起こります。**既存のクリティカル演出と倍率演出を2回続けて出さないでください。** どちらかに寄せてください。おすすめは、クリティカルのときは `×2倍` の文字の上に小さく `会心` と添えて、音は**オーケストラ・ヒットだけ**にする形です。

## 8. 反射

`reflect` で跳ね返ったダメージには `boosts` を付けていません（攻撃した側の倍率であって、跳ね返した側のものではないため）。反射の演出は既存のままでお願いします。

## 9. 音

**オーケストラ・ヒット**（Orchestra Hit / ORCH HIT）。DS時代の音源にあった、あの短い金管＋ストリングスの一撃です。

- 長さ 0.4〜0.8秒、立ち上がりが速いもの
- 倍率が高いほどピッチを上げる、または音量を上げる（×1.5 → ×2 → ×3 で段階が感じられると良いです）
- 既存のヒット音と**重ねる**のではなく、一拍おいて**単独で**鳴らしてください

ファイル名は `public/sounds/orchestra-hit.*` あたりでお願いします。音源の用意が難しければ声をかけてください。

## 10. 設定

連打でスキップできるようにしてください。演出が長いと2周目がつらくなります。既に演出オフの設定があるなら、そこに入れてください。

## 11. core側でやらないこと

- **倍率をUIで計算し直さないでください。** 守るかどうか、種が乗るかどうか、確率の結果まで含めて core が決めています
- `amount` は**すでに倍率が乗ったあとの値**です。`amount × boostTotal` にはしないでください
- `boosts` の順番は core 側で意味のある順（プレイヤーが仕込んだものが先、属性が最後）に並べています。並べ替え不要です

## 12. 確認用

`docs/MOVE_EFFECTS.md` の10章に実測値があります。

```
通常            ダメージ  4   ×1    （boosts なし）
攻撃力2倍        ダメージ 10   ×2    攻撃力上昇×2
種（炎で追撃）    ダメージ  5   ×1.5  種×1.5
攻撃力2倍＋種     ダメージ 15   ×3    攻撃力上昇×2 / 種×1.5
```

ラムチャージ（`ram-charge`）を撃った次のターンに攻撃すれば `attackUp` が確実に出ます。これが一番手軽な確認方法です。
