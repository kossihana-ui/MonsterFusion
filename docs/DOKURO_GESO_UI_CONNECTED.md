# ドクロゲソ：UI接続完了（2026-11-13）

core側の仕様と測定値は core の [DOKURO_GESO.md](../../MonsterFusion-Core/docs/DOKURO_GESO.md) です。

## 接続したもの

- `src/mocks/game.ts`
  - `getItems()` … `getConsumables(session)`。パーツとは別の持ち物
  - `previewEnemyCapture()` … 使えるか・誰に使うか。判断はcoreが返す
  - `captureEnemy(requestId)` … 捕獲。成功時だけアイテムが減る
  - `receiveArenaReward()` を `claimArenaRewardInSession` に差し替え。パーツとアイテムが
    それぞれの持ち物に入る
- `src/components/CaptureItemCard.tsx` … 「準備中」を撤去。所持数、使用ボタン、
  coreが返した理由文を表示。戦闘外では持っていない旨を案内
- `src/pages/Battle.tsx` … アイテムボックスから使用。成功すると行動コマンドが消え、
  「〇〇が仲間になった！」と入口へ戻るボタンを表示。報酬メッセージにアイテム名も載る
- アイテムボックスの個数表示にアイテムを含めた

**UIは成功率もドロップ抽選も判定しません。** `previewEnemyCapture().ok` と
`captureEnemy()` の戻り値をそのまま使っています。`requestId` は押すたびに
`crypto.randomUUID()` を発行するので、連打しても1個しか消費しません。

## 捕獲したあとの扱い

捕獲するとその挑戦は終わります（勝ち星も報酬もなし）。これはcoreの決定で、
理由は core の DOKURO_GESO.md の3章にあります。UIは行動コマンドを下げて、
入口へ戻る導線だけを出します。

## 検証

`scripts/check-capture-ui.mjs` を追加しました。所持なしでの拒否、ボスドロップ、
アイテムボックス、プレビュー、捕獲、1個だけ消費、連打、捕獲個体の融合、再スタートまで
通します。ボス撃破は普通には起きないので、スクリプト内だけアリーナの強さと
ドロップ率を一時的に下げています（終了時に元へ戻します）。

実画面でも確認済みです。ボスを倒して「獲得：大顎、王冠、ドクロゲソ」、次の挑戦で
アイテムボックスから使用して所持3→4体、アイテム1→0。

## 報告：今の設定ではほぼ手に入りません

スターターのまま2000回ずつアリーナを回した結果です。

```
          ボスまで到達    ボス撃破    ドクロゲソ入手
Moss       199/2000         1          0  (0.00%)
Ignis      100/2000         0          0  (0.00%)
Aqua       645/2000       186         16  (0.80%)
```

**10%の抽選より前に、ボス撃破そのものが関門です。** 融合で強くしてから挑めば
上がりますが、モスとイグニスは現状ほぼ到達できません。

仕様どおりの実装なので数値は変えていません。変えるなら
`DEFAULT_ARENA_CONFIG.bossCaptureItemChance`（現在0.1）か、
「撃破時」ではなく「ボスに到達した時」に配る、のどちらかです。
