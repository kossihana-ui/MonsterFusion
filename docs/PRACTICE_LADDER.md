# はじめての挑戦（練習ラダー）

2026-11-14。「初見が10分で終わらないようにする」への実装です。

## 1. 何が問題だったか

測定値です。スターターのままアリーナに挑んだときの到達は、

```
Moss 中央値 3戦 ／ Ignis 中央値 2戦 ／ Aqua 中央値 4戦
```

負けると出場した仲間を失い、手持ちは3体しかありません。**つまり初見の人は、
何が起きているか分からないうちに10分ほどでゲームオーバーに着きます。**
「難しい」のではなく「学ぶ前に終わる」状態です。

## 2. 作ったもの

**同じラダーを、相手だけ弱くしたもの**です。新しい仕組みは足していません。

| | 練習 | 通常 |
|---|---|---|
| 相手の強さ | `practiceStrength` 倍（既定 0.75） | 等倍 |
| 負けたとき | **仲間を失わない** | 失う |
| 素材・ドクロゲソ | **出ない** | 出る |
| 順位 | 加わらない | 加わる |
| 長さ・ボス・竜 | 通常と同じ | 同じ |

**素材が出ないことが重要です。** 危険のないラダーで素材が手に入るなら、
それが最も効率の良い稼ぎ方になり、「負けると失う」というこのゲームの芯が
消えます。練習は**何も賭けず、何も得ない**場所です。

## 3. 効果（60回×3体、既定技セット・貪欲な自動操作）

```
              通常ラダー        練習ラダー
Moss          中央値 3戦   →    中央値 10戦
Ignis         中央値 2戦   →    中央値  5戦
Aqua          中央値 4戦   →    中央値 12戦
```

**6戦目のボスまで届くようになります。** ここが狙いで、初見の人が
「ボスが出る」「報酬がある」「技の組み合わせで結果が変わる」を
一度は体験してから、本番のラダーに出られます。

数字は `practiceStrength` ひとつで調整できます。0.7 では中央値19戦まで
伸び、何も得られないラダーに長居させすぎました。0.85 ではボスがまた
届かなくなりました。

## 4. 実装

- `config.arena.practiceStrength` — 強さの倍率。コードに数字はありません
- `ArenaRun.practice?: boolean` — 任意フィールドなので、**これ以前のセーブも
  そのまま通常の挑戦として読めます**
- `startArena(..., { practice: true })` → `createArenaEnemy(..., practice)` →
  `strengthFor(index, config, practice)`
- `claimArenaReward` — 練習なら何も渡さず、ただ claimed にだけ入れます
- `settleBattleLoss(..., { stakes: false })` — 戦闘は「決着済み」として
  記録しますが、誰も失われません。二重清算の防止はそのまま働きます
- `practiceSeason()` / `rankedSeasons()` — 練習は順位の対象外です

## 5. UI

- 入場画面で**いちばん上**に出し、「おすすめ・初回」と表示します
- **記録がまだ無い人は練習が初期選択**、記録がある人は今週のラダーです
- 見出しの注意文は練習のとき差し替えます。失わないのに「失います」と
  書くのは、ゲームが嘘をついていることになります
- 敗北画面も同じで、練習では「◯◯は無事です」と出ます
- 説明書に節を追加しました

## 6. 残っている判断

**練習中にドクロゲソを使えます。** 通常ラダーで手に入れた1個を練習で使えば、
危険を負わずに相手を仲間にできます。ドクロゲソ自体がほぼ手に入らない
（1ランあたり0〜0.8%）ので実害は小さいと判断しましたが、塞ぐなら
`previewCapture` に練習の判定を足すだけです。
