# お金を受け取れるようにする

2026-11-24。**いまの状態と、残っている手続きです。**

## itch.io：投げ銭を有効にしました

```
Pricing   $0 or donate   （有効）
Suggested donation   $2.00   （約¥300）
```

**ただし、まだ1円も受け取れません。**

itch.ioの編集画面にこう出ています。

```
You don't have payment configured
```

**支払い先が登録されていないので、投げ銭ボタン自体がページに出ません。**
公開ページを確認しましたが、「Support this game」は表示されていません。
**壊れたボタンが出るよりは正しい動きです。**

### あなたがやること（こちらではできません）

itch.ioの**アカウント設定 → Payment**（編集画面の「Edit account」リンク）で、
**PayPal か Stripe** をつなぎます。

**これは代わりにできません。** 銀行口座・本人確認・税務情報は、あなた自身の
ものだからです。**こちらから聞くこともしません。**

つないだ瞬間に、ゲームページへ投げ銭ボタンが出ます。

## 前払いのある店とない店

| | 前払い | 手数料 | 1本目から黒字か |
|---|---|---|---|
| **itch.io** | ¥0 | 設定可（既定10%） | **はい** |
| **BOOTH** | ¥0 | 5.6% ＋ 振込手数料200〜300円 | **はい** |
| **Steam** | **$100（約¥15,000）** | 30% | **いいえ。¥500なら43本売ってから** |

Steamだけ、**売れる前に払う**構造です。$100は売上$1,000に達したあと回収
できますが、それまでは出ていったままです。

BOOTHは公式ガイドで確認しました。pixivアカウントでそのまま開店でき、
ダウンロード販売可、**売上は翌月20日から5営業日以内**に振り込まれます。

---

## 正直な見込み

```
売上 ＝ 見られた回数 × 買う率 × 値段 × (1 − 手数料)
```

いま見られているのは**週16回**です。月100人が遊んで2%が¥300払って、
**月¥600**。**店を増やしても、この式の最初の項は変わりません。**

**それでも投げ銭を置く理由は、置くのに費用がかからないからです。**
損がないので、置いておいて人が増えるのを待てます。

逆に**Steamを先に買うのは、増える前に¥15,000払うこと**になります。
週16人が週300人になってからで遅くありません。
