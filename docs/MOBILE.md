## 2026-11-19 追記：実機で2つ見つかりました

### ① 挑むラダーが「はじめての挑戦」しか選べなかった

> 挑むラダーもアリーナの扉に埋もれて、はじめての挑戦しか選べません

**4つあるラダーのうち、見えていたのは1つ半でした。**

```
ラダー4つの高さ   430px
入っていた箱      367px   ← 63pxぶんが箱の中で切れる
```

アリーナ入口は、**箱の中が独立してスクロールする**作りでした。
PCでは正しい判断です（入場ボタンが画面の下に落ちないため）。
**スマホでは、ページ自体がスクロールする中にもう1つスクロール領域を作る形**に
なり、指で動かすと**たいていページのほうが動きます。** 箱の中は動きません。

その切れた縁の真下に扉のパネルが来るので、**扉に埋もれて見えた**わけです。
そして選べる1つが「はじめての挑戦（練習）」——**唯一、本番ではないラダー**でした。

768px以下では箱の高さ制限と内側スクロールをやめました。**スマホはページが
スクロールします。** 4つとも最後まで出ます。

### ② 名前の入力でキーボードが切れた

> プレイヤーネームの入力ウィンドウが右上にでてた、な、は、以上が切れていて
> 入力できませんでした

**これはこちらだけでは直しきれません。正直に書きます。**

itch.ioのスマホ版は、ゲームを**フルスクリーン要素の中**で動かします。
フルスクリーン中にテキスト入力へフォーカスすると、ブラウザが入力欄を
画面内へ送る動作が狂うことがあります。**日本語キーボードは英語より背が高く、
変換候補の帯もある**ので、はみ出すと「な・は」から下が消えます。

やったこと：`src/shared/keyboardRoom.ts`。タッチ画面でテキスト欄に
フォーカスが入ったら、**キーボードが開き終わってから**（`visualViewport`の
resizeで分かります）**残った画面の真ん中へ入力欄を送ります。**
スクロールするだけで、位置は動かしません。PCでは何もしません。

**これで直らない可能性があります。** 切り分けのため、同じスマホで
GitHub Pages版（`https://kossihana-ui.github.io/MonsterFusion/`）を
**ブラウザで普通に開いて**同じ入力欄を試してください。

- **Pages版なら入力できる** → itch.ioのフルスクリーンが原因です。
  itch側の「Fullscreen button」を切るのが次の手になります
- **Pages版でも切れる** → こちらの問題です。別の直し方を探します

## 2026-11-19 追記：切り分けの結果と、技の欄

### ① 名前入力の切り分け：itch.ioのフルスクリーンが原因でした

GitHub Pages版をスマホのブラウザで開くと、**縦画面で問題なく入力できました。**
同じコードなので、**原因はitch.ioの再生のしかた**です。

itch.ioのスマホ版はゲームを**フルスクリーン要素の中**で動かします。その中で
テキスト入力にフォーカスすると、入力欄を画面内へ送る動作が狂い、
背の高い日本語キーボードが「な・は」から下で切れます。

**これはこちらのコードでは直せません。** できる手は3つです。

| 手 | 効果 | 代償 |
|---|---|---|
| スマホの人にPages版を案内 | 確実に直る | URLが2つになる |
| itchの Mobile friendly を切る | フルスクリーン再生をやめる | スマホで縮小表示になり、かえって遊びにくい |
| 様子を見る | — | 名前を入れたい人が入れられない |

**いまのところ、スマホはPages版を案内するのがいちばん確実です。**

### ② 技の欄が大きすぎた

> これは縦画面で動作し、すべて入力はできますが、技の欄が大きすぎてプレイしにくいです

測ると、**技の欄だけで813px**ありました。390pxの画面で、**1画面まるごとボタン**です。
その上に戦場があるので、**モンスターを見る→下まで運んで技を押す→また戻る**に
なっていました。

```
            直す前   直したあと
技の欄       813px    531px
```

**文字は1pxも小さくしていません。書いてある内容も減らしていません。**
削ったのは3つです。

**「攻撃」と「守る」を横に並べました。** 1行ずつしか書いていないのに、
1つで横幅を使い切っていました。

**ⓘを技の下から右へ移しました。** 44pxの丸ボタンです。文字の
「効果・使う部位」はスマホでは消しています（ⓘの字と読み上げ用のラベルが
残るので、意味は失われません）。**1技あたり50px浮きます。**

**余白を18px→12pxにしました。**

技を2列にする案も測りましたが、**文字の折り返しが増えて1枚247pxまで伸び、
2列にしたほうが縦に長くなりました。**やめています。

```
            360px   390px   1280px
技の欄       548     531     （変更なし）
横はみ出し     0       0        0
44px未満     0個     0個        —
```

### 案内を出しました（itch.ioのページ冒頭）

```
スマホの方へ：この埋め込みでは名前の入力ができません（キーボードが隠れます）。
スマホからは https://kossihana-ui.github.io/MonsterFusion/ を開いてください。
中身は同じものです。
```

公開ページに出ていることを確認済みです。

**1つだけ注意があります。** itch.ioの中とPages版では**保存場所が別**です
（ブラウザはURLごとにデータを分けます）。**両方で遊ぶと別々のセーブになります。**
移したいときは「セーブの引き継ぎ」の引き継ぎコードを使ってください。

            前々回   前回   今回

### 残したもの

**MPと、押せない理由。** 「MP 7 · ふつう」「MP不足」「拘束中は出せない」です。
