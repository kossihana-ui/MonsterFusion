2026-11-19。依頼された6項目を、**まず測ってから**直しました。

## 測った結果：4つは既にできていました

| 項目 | 状態 |
|---|---|
| ① viewportメタタグ | **既にあり**（`index.html:5`） |
| ② 固定px幅をやめる | **既にそう**。`main`は`max-width:1440px`、`* { box-sizing: border-box }` |
| ③ 360pxで横スクロールなし | **既にゼロ**。全6画面で測って0px |
| ③ 横並び→縦並び | **既に切替済み**。ソウルメイク760px、戦闘コマンド560px、アリーナ入口800pxなど |
| ④ タップ領域44px | **不足していました** |
| ⑤ 入力欄16px以上 | **不足していました** |
| ⑥ PC（769px以上）据え置き | 変えていません |

**無いものを作るより、本当に壊れている2つを直すほうが安全です。**
前に一度、測った数字だけを見て画面を詰めすぎて戻した経緯があるので、
**既に動いているものには触っていません。**

## ④ 指で押せない大きさでした（360px時点）

```
検索欄                39px
おまかせで決める       39px
＋ モンスターを登録    36px
ⓘ 遊び方・説明書      29px
ソウルメイクへ        25px   ← 指の半分
```

指の腹はおよそ44pxです。**狙って押すものになっていました。**

`min-height: 44px` を使っています。**足りないものだけが伸びます。**
メニューの横一列（47px）と戦闘コマンド（107〜154px）は元から超えているので、
**何も変わっていません。**

## ⑤ iOSが勝手に拡大していました

入力欄とセレクトが全部 **11px**（引き継ぎコード欄だけ12.88px）でした。
**iOSは16px未満の入力欄にフォーカスすると、ページを拡大します。**
さっきまで収まっていた画面が、入力し始めた瞬間に横にはみ出します。

全部16pxにしました。**768px以下だけ**です。

## ③ 区切りを 700px → 768px に変えました

メニューが左の縦列から上の横一列に変わる境目です。依頼どおり768pxにしました。
**ほかのCSSファイルが列を折るのも760px前後なので、揃いました。**
