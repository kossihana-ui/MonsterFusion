# 隠し遺伝子を低頻度にする依頼（core担当向け）

## ユーザーの希望
隠し遺伝子が現れる頻度を今より下げ、出たときの特別感を持たせたい。

## 現状の確認
DEFAULT_GENETICS_CONFIG.atavismRate = 0.12。
gameteFrom が「各座位・各親の隠しアレルを渡すか」を判定する。
これは融合1回あたり12%の発現率ではない。継承と実際の発現も異なる。

## coreへの調整案（未適用）
まず atavismRate = 0.01 を試す。数値はUIで上書きせず、core既定値として管理する。
固定seedの複数世代のシミュレーションで、融合1回あたりの隠し遺伝子の継承率と、
実際に見た目に現れた割合を別々に計測し、体感に合わせて調整してほしい。
突然変異率 mutationRate は別の仕組みなので、この依頼では変更しない。
既存個体のgenes/phenotype/statsは書き換えず、新規融合に適用する。

## 接続API
既存の fuseDetailed(parentA, parentB, context) と describeMonster(monster)、
describeFusion(child, evolved) のままで接続可能。新しいUI専用確率計算は不要。
もし融合ごとの上限や抽選方式を変更するなら、core側の既存型に沿って実装し、
seed再現性・親の不変性・複数世代の継承テストを維持する。

## UIで実施済み
今、現れている特徴をパーツ画像付きで表示。
未発現の劣性の特徴と隠し遺伝子は、閉じた詳細欄に分けて格納。
突然変異は各特徴の印として表示。優性・劣性は強弱ではないと説明。
画像はtag.valueに対応し、隠れた特徴を現在の姿の画像で代用しない。
確率の変更は未適用。現在のUIには確率の数値を表示しない。
