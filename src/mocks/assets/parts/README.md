# 合成パーツ v1

35枚の初版ドット絵です。既存スターターをデザインの参考に、5色・付け根原点に合わせて描き直しました。完成イラストそのものの画風を完全再現したものではありません。

## 編集と確認

`npm.cmd run sprites:build` で `build-parts.mjs` の整数グリッド定義からPNG・manifestを再生成します。アンチエイリアスは使いません。参照色は #1b2030 / #4a4a6a / #8a8ab0 / #c8c8e0 / #ff00ff の5色、アルファは0または255のみです。accentは発光目・宝石・エネルギーに限定し、体には使いません。花は体色に従います。

`npm.cmd run sprites:check` で公開APIのrequiredPartKeysとの一致、PNGの全画素・寸法・原点、200世代の素材網羅性、色置換、アンカー変換、反転、欠損スキップを検証します。Node 24を使用してください。

画像確認を出力する場合は、任意で `SPRITE_CANVAS_MODULE` にインストール済み@napi-rs/canvasのindex.js絶対パスを設定して同じ検証を実行します。通常の開発・ビルド・検証にはこの追加ライブラリは不要です。

## 素材の原点

`manifest.json` が唯一のメタデータです。bodyは64×64全体の中に描き、coreのrig.originと同じ点を原点としています。その他は、角・翼・尻尾の付け根、目・口の中心、頭部装飾の底面を原点とします。巻き角は根元より下へ回り込むよう、他の角より原点を上へ移しています。

`manifest.ts` はViteが静的に解決できる画像URL一覧です。再生成で更新されます。原点調整は生成元で行い、マニフェストだけを手修正しないでください。

## 描画・動作

- coreへのimportは@core/core/index.tsのみ。
- renderer.tsでcomposeAppearance・色置換・素材のキャッシュ・欠損レイヤーのスキップを処理。
- MonsterSprite.tsxでposeAt、個体ID由来のphase、待機への復帰、画面外での描画抑制、アンマウント時の停止、動きを減らす設定に対応。
- coreのfacingRightは動きの方向を反転するため、UIではアンカー座標と素材自体も反転します。回転→拡縮は各アンカーの移動後に適用します。
- バトルはcoreログの順にattack/hurtを再生。演出中の重複操作を防止し、画面を離れたらキャンセルします。
- スターター・融合した子は合成表示。アップロードしたPNGは未解析なので、その個体は入力画像のまま表示します。

coreのBODY_RIGSやアニメーション定数は変更していません。全組み合わせの見栄え・極端なサイズでの端の収まりは今後のアート調整対象です。初版の画像プレビューはartifacts/spritesにあります。
